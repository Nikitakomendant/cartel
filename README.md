# CARTEL — корпоративний сайт і CMS

Сайт cartel.ua за ТЗ «Редизайн і розробка корпоративного сайту CARTEL»: публічний сайт UA/EN, модульна CMS для маркетингу, HR-модуль, форми із захистом від спаму, SEO та аналітика.

**Платформа:** Node.js 22 + Express + SQLite + власна CMS. Один сервіс, одна база-файл, без платних ліцензій і без привʼязки до розробника: весь код, база й медіа належать CARTEL.

## Захист

Детально — `docs/SECURITY.md`. Коротко: CSP з nonce, HSTS, заборона iframe, захист від CSRF, XSS (санітизація + автоекранування), SQL-інʼєкцій (лише підготовлені запити), перебору паролів (ліміти + блокування акаунта), 2FA для персоналу, сесії на сервері з тайм-аутом, перевірка файлів за сигнатурою та перекодування фото, резюме поза публічною папкою, антиспам у формах (honeypot + підписаний токен часу + ліміти + опційно Turnstile), блокування сканерів уразливостей, журнал дій, резервні копії. `tests/security.test.js` — 10 автоматичних перевірок.

> ⚠️ **Поточний cartel.ua, ймовірно, зламаний.** У збереженій копії головної сторінки (`pages.json` зі старого репозиторію) внизу є приховані посилання на онлайн-казино («toto», «judi bola», «slot4d», «boscuan303») — типова SEO-інʼєкція у WordPress. Це шкодить репутації в Google. До запуску нового сайту варто: змінити всі паролі WordPress/хостингу/FTP, оновити WordPress і плагіни, перевірити Google Search Console на «проблеми безпеки».

## Запуск

### Локально
```bash
npm ci
cp .env.example .env          # заповніть ADMIN_PASSWORD (≥10 символів, літери й цифри)
npm start                     # http://localhost:3000, CMS — http://localhost:3000/admin
```
При першому запуску база заповнюється контентом зі старого сайту. Якщо `ADMIN_PASSWORD` не задано, пароль адміністратора записується у `data/INITIAL_ADMIN_PASSWORD.txt` (видаліть файл після входу).

### Сервер (рекомендовано: VPS 2 ГБ RAM, Ubuntu 24.04, Docker)
```bash
git clone … /srv/cartel && cd /srv/cartel
cp .env.example .env && nano .env          # BASE_URL, APP_SECRET, SMTP_*, ADMIN_*
docker compose up -d --build
sudo cp deploy/nginx.conf /etc/nginx/sites-available/cartel.ua && sudo ln -s ../sites-available/cartel.ua /etc/nginx/sites-enabled/
sudo certbot --nginx -d cartel.ua -d www.cartel.ua && sudo systemctl reload nginx
# щоденна резервна копія о 04:00
( crontab -l; echo "0 4 * * * cd /srv/cartel && docker compose exec -T cartel node scripts/backup.js" ) | crontab -
```
Орієнтовна вартість: VPS 2 ГБ (Hetzner / DigitalOcean) — $6–12/міс. SMTP: Google Workspace / Brevo / Mailgun (безкоштовні тарифи достатні для заявок). Опційно Cloudflare (безкоштовний план) — CDN і захист від DDoS.

### Фото
- Новий сайт: фото підтягуються автоматично при першому запуску (≈1 хв на обробку).
- Уже запущений сайт: `docker compose exec cartel node scripts/replace-photos.js` — спершу робить резервну копію бази, зміни видно в історії CMS.
- Змінити набір: відредагуйте `seed-assets/photos.json` (номер фото Pexels для кожного бренду й сторінки), покладіть файли в `seed-assets/photos/<номер>.jpg`.

### Оновлення та відновлення
- Оновити код: `git pull && docker compose up -d --build` (база й медіа у volumes не зачіпаються).
- Відновити базу: зупинити контейнер, підставити файл із `data/backups/` як `data/cartel.db`, запустити.
- Втрачено доступ адміністратора: `docker compose exec cartel node scripts/create-admin.js email@cartel.ua`.

### Тести
```bash
# сервер має бути запущений з порожньою базою
python3 tests/e2e_acceptance.py http://localhost:3000 admin@cartel.ua <пароль>
BASE=http://localhost:3000 ADMIN_PASSWORD=<пароль> node --test tests/security.test.js   # останній тест блокує ваш IP на 1 год — перезапустіть сервер
```

## PeopleForce
Задайте `PEOPLEFORCE_API_KEY` у `.env`, потім HR вмикає «Дублювати кандидатів у PeopleForce» у CMS → Контакти рекрутера. Кожен відгук створює кандидата (`POST /recruitment/candidates`). PeopleForce вимагає email кандидата — відгуки без email залишаються лише на сайті. Статус синхронізації видно в картці відгуку. Перед запуском перевірте інтеграцію з тестовим ключем.

## Що потрібно від CARTEL перед запуском
1. Власні фото й відео закладів. Зараз на сайті 105 атмосферних фото з Pexels (безкоштовні для комерційного використання, 2200 px; список — `seed-assets/photos.json`). Це **не фото закладів CARTEL**: перед запуском замініть їх на власну зйомку — гості мають бачити справжні інтерʼєри та страви.
2. URL офіційного сайту **Mountain Residence Premium Villas & SPA** (кнопка зʼявиться автоматично).
3. Посилання на системи бронювання готелів (зараз кнопка «Забронювати» дзвонить на рецепцію).
4. Точні точки брендів на карті (зараз — орієнтовні в межах Буковелю; ставляться кліком на карті в CMS).
5. Показники компанії для Home (зараз 2004 / 17 ресторанів / 2 готелі / 3 міста — звірте).
6. Команда, нагороди, фото подій (Тіна Кароль і svet — створені як чернетки).
7. Текст політики конфіденційності від юриста (є шаблон).
8. SMTP-доступ, email-отримувачі заявок, ID GA4 / GTM / Meta Pixel, Telegram/Viber рекрутера.

## Структура
```
server.js               точка входу
src/config.js           налаштування з .env
src/db.js               SQLite, контент, історія версій
src/schema.js           бібліотека блоків і типи контенту (з нього генерується редактор CMS)
src/settings-schema.js  сторінки налаштувань
src/security.js         паролі, 2FA, токени, санітизація, заголовки, антисканер
src/auth.js             сесії, ролі, CSRF
src/media.js            обробка фото/відео, резюме
src/routes/public.js    сайт, форми, sitemap/robots
src/routes/admin.js     CMS
views/                  шаблони (blocks/ — по одному на блок)
public/                 CSS, JS, шрифти, Leaflet
data/                   база, резюме (приватно), бекапи — НЕ публікується
uploads/                фото і відео з CMS
```
